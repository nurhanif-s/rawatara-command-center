Versi 1.0 · 27 November 2026 · Berlaku untuk RAWATARA Command Center V6.0.

1. Pengelola dan cakupan

RAWATARA Command Center merupakan proyek independen yang dijalankan secara lokal oleh pemilik akun. Kebijakan ini menjelaskan data yang diproses aplikasi desktop dan website dokumentasi.

2. Data TikTok yang diminta

Jika pengguna memberikan izin melalui Login Kit, aplikasi meminta akses user.info.basic, user.info.stats dan video.list. Data yang diproses meliputi ID akun (open_id), nama tampilan, jumlah followers, following, likes dan video; serta ID video, judul, waktu publikasi, views, likes, komentar (jumlah), dan share (jumlah). Aplikasi mencatat waktu dan status sinkronisasi. Aplikasi tidak meminta kata sandi TikTok atau isi pesan pribadi.

3. Tujuan dan dasar akses

Data digunakan untuk menampilkan statistik, histori, ekspor dan analisis performa milik akun yang mengizinkan akses. Otorisasi TikTok dilakukan dengan persetujuan pengguna. Aplikasi tidak menggunakan data untuk menjual profil pengguna, membuat engagement palsu atau mengedit konten TikTok.

4. Penyimpanan dan pihak ketiga

Client key, client secret dan token disimpan sementara di memori backend pada V6.0 dan tidak dimaksudkan untuk disimpan dalam database. Snapshot statistik dan log sinkronisasi disimpan dalam SQLite lokal (data/lab.sqlite3). Data yang dimasukkan melalui fitur kalender, CSV dan pencatatan biaya juga tersimpan lokal. Data tersebut tidak dikirim ke website dokumentasi oleh aplikasi. Permintaan otorisasi dan sinkronisasi dikirim ke TikTok melalui API resminya. Website statis tidak memasang formulir, tracker atau cookie sendiri; penyedia hosting dapat memproses informasi koneksi sesuai kebijakannya.

5. Retensi, pencabutan dan penghapusan

Histori lokal disimpan sampai pengguna menghapusnya. Tombol Putus koneksi menghentikan sinkronisasi dan menghapus kredensial dari memori lokal, tetapi tidak menghapus histori maupun otomatis mencabut izin di TikTok. Cabut akses aplikasi juga melalui pengaturan izin akun TikTok. Untuk menghapus seluruh data aplikasi, tutup aplikasi, lalu hapus data/lab.sqlite3 beserta file jurnal terkait dan salinan backup/CSV yang tidak lagi dibutuhkan. Perhatian: tindakan ini juga menghapus data konten dan keuangan lokal. Penghapusan selektif belum tersedia melalui UI V6.0; hubungi pengelola sebelum menghapus data apabila perlu menyimpan data lain.

6. Keamanan dan hak pengguna

Dashboard dirancang untuk localhost. Jangan mempublikasikan database, backup, client secret, token atau membuka dashboard ke jaringan publik. Akses, koreksi, ekspor dan penghapusan data dapat diminta kepada pengelola melalui halaman bantuan. Untuk layanan TikTok, lihat juga kebijakan privasi TikTok.

7. Perubahan

Kebijakan akan diperbarui jika fitur, penyimpanan atau penggunaan data berubah. Periksa tanggal versi sebelum memberikan otorisasi baru.
