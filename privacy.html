Privacy Policy

Versi 1.1 · 28 November 2026 · Berlaku untuk RAWATARA Command Center V6.0 dan V7.0.

1. Pengelola dan cakupan

RAWATARA Command Center merupakan proyek independen yang dijalankan secara lokal oleh pemilik akun. Kebijakan ini menjelaskan data yang diproses aplikasi desktop dan website dokumentasi.

2. Data TikTok yang diminta

Jika pengguna memberikan izin melalui Login Kit, aplikasi meminta akses user.info.basic, user.info.stats dan video.list. Data yang diproses meliputi ID akun (open_id), nama tampilan, jumlah followers, following, likes dan video; serta ID video, judul, waktu publikasi, views, likes, komentar (jumlah), dan share (jumlah). Aplikasi mencatat waktu dan status sinkronisasi. Aplikasi tidak meminta kata sandi TikTok atau isi pesan pribadi.

3. Tujuan dan dasar akses

Data digunakan untuk menampilkan statistik, histori, ekspor dan analisis performa milik akun yang mengizinkan akses. V7.0 juga menggunakan snapshot statistik untuk menghitung perubahan target pertumbuhan, membandingkan performa video pada usia yang sebanding, dan membuat rekomendasi serta laporan lokal. Otorisasi TikTok dilakukan dengan persetujuan pengguna. Aplikasi tidak menggunakan data untuk menjual profil pengguna, membuat engagement palsu atau mengedit konten TikTok.

4. Penyimpanan dan pihak ketiga

Pada V6.0 dan secara default pada V7.0, client key, client secret dan token hanya disimpan sementara di memori backend. Pada V7.0, pengguna Windows dapat secara opsional mengaktifkan penyimpanan sesi lokal untuk memulihkan koneksi setelah aplikasi ditutup. Kredensial, token, status jadwal dan interval sinkronisasi disimpan dalam file data/tiktok7-session.dpapi yang dienkripsi dengan Windows Data Protection API (DPAPI) untuk pengguna Windows saat ini. File tersebut tidak dikirim ke website dan tidak disertakan dalam backup SQLite. Tidak ada penyimpanan alternatif berupa teks biasa jika enkripsi gagal. DPAPI tidak melindungi dari malware yang berjalan dengan hak pengguna Windows yang sama. Jangan mengaktifkan opsi ini pada komputer bersama atau membagikan file sesi. Snapshot statistik dan log sinkronisasi disimpan dalam SQLite lokal (data/lab.sqlite3). Data yang dimasukkan melalui fitur kalender, CSV dan pencatatan biaya juga tersimpan lokal. Data tersebut tidak dikirim ke website dokumentasi oleh aplikasi. Permintaan otorisasi dan sinkronisasi dikirim ke TikTok melalui API resminya. Website statis tidak memasang formulir, tracker atau cookie sendiri; penyedia hosting dapat memproses informasi koneksi sesuai kebijakannya.

5. Retensi, pencabutan dan penghapusan

Histori lokal disimpan sampai pengguna menghapusnya. Tombol Putuskan koneksi lokal menghentikan koneksi dan menghapus kredensial dari memori lokal serta file sesi tersimpan pada V7.0 apabila penghapusan berhasil; tindakan ini tidak menghapus histori maupun otomatis mencabut izin di TikTok. Pengguna V7.0 juga dapat menonaktifkan penyimpanan sesi tanpa memutus koneksi aktif; file sesi lokal akan dihapus apabila penghapusan berhasil. Sesi yang kedaluwarsa, dicabut, atau gagal dipulihkan mungkin memerlukan otorisasi ulang. Cabut akses aplikasi juga melalui pengaturan izin akun TikTok. Untuk menghapus seluruh data aplikasi, tutup aplikasi, lalu hapus data/lab.sqlite3 beserta file jurnal terkait, file sesi data/tiktok7-session.dpapi jika ada, dan salinan backup/CSV yang tidak lagi dibutuhkan. Perhatian: tindakan ini juga menghapus data konten dan keuangan lokal. Penghapusan selektif histori belum tersedia melalui UI V6.0/V7.0; hubungi pengelola sebelum menghapus data apabila perlu menyimpan data lain.

6. Keamanan dan hak pengguna

Dashboard dirancang untuk localhost. Jangan mempublikasikan database, backup, file sesi, client secret, token atau membuka dashboard ke jaringan publik. Akses, koreksi, ekspor dan penghapusan data dapat diminta kepada pengelola melalui halaman bantuan. Untuk layanan TikTok, lihat juga kebijakan privasi TikTok.

7. Perubahan

Kebijakan akan diperbarui jika fitur, penyimpanan atau penggunaan data berubah. Periksa tanggal versi sebelum memberikan otorisasi baru.
