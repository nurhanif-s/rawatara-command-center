Kelola konten.
Ukur pertumbuhan.

RAWATARA Command Center adalah aplikasi desktop lokal untuk merencanakan konten affiliate, mengevaluasi performa video, serta memantau pertumbuhan audiens asli.

Panduan aplikasi

Content Intelligence

Riset produk manual, draf hook dan skrip berbasis template, kalender produksi, serta evaluasi A/B.

Growth Engine

Target 30 hari, evaluasi data performa, misi harian, pencatatan biaya dan komisi.

TikTok Integration

Integrasi baca-saja melalui Login Kit dan API resmi, dalam tahap pengujian. Tidak mengirim engagement atau memublikasikan video.

Cara penggunaan

  1. Jalankan aplikasi desktop V6.0 pada komputer pemilik akun.
  2. Buka dashboard lokal pada http://127.0.0.1:8765 dan pilih TikTok Integration V6.
  3. Jika akses Sandbox telah tersedia, masukkan kredensial aplikasi secara lokal, lalu otorisasi akun di TikTok.
  4. Jalankan sinkronisasi dan periksa hasil serta log. Data kumulatif TikTok disimpan terpisah dari data harian yang diimpor.

Status integrasi

Koneksi TikTok asli masih dalam pengujian dan belum memperoleh persetujuan produksi. Website ini adalah dokumentasi; dashboard dan kredensial tidak dihosting di sini. Data transaksi affiliate belum tersinkronisasi lewat API.

Data dan kontrol pengguna

Pengguna dapat melepas koneksi lokal kapan saja. Statistik historis disimpan pada perangkat pengguna. Baca Privacy Policy untuk rincian akses, penyimpanan, dan penghapusan.
